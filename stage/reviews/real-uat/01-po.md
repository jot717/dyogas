# Product Owner — Real UAT Gaps → Requirements

**Agent:** Product Owner  
**Input:** `stage/REAL_ACCEPTANCE_REPORT.md`  
**Decision:** Convert blockers into product requirements. Spec update **required**.

## User value

Ask My Brain must feel like a **trusted collaborator**, not an auto-complete dump.  
The owner must control what becomes accepted answer / learned knowledge.

## Requirements

| ID | Requirement | Maps to |
|----|-------------|---------|
| REQ-PB-ASK-01 | Ask produces a **proposed answer** (status=`proposed`), never silently final | REAL-GAP-01 |
| REQ-PB-ASK-02 | UI shows **Evidence** (retrieved knowledge titles + excerpts + knowledgeIds) separate from the proposal | REAL-GAP-03 |
| REQ-PB-ASK-03 | Owner can **Approve**, **Edit then Approve**, or **Reject** the proposal | REAL-GAP-02 |
| REQ-PB-ASK-04 | On Approve (optional checkbox): **learning update** — store Q&A / corrected answer as new pending or approved knowledge with provenance to Ask session | REAL-GAP-04 |
| REQ-PB-ASK-05 | Reject discards proposal; no SoR write | REAL-GAP-02 |
| REQ-PB-ASK-06 | Prefer Gemini grounded prose when key present; fallback must still be framed as a **proposal**, not a raw frontmatter dump | REAL-GAP-05 |
